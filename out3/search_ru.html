1. 상세검색 활용

정확히 일치하는 단어/문장이 변형없이 입력된 순서대로 정확하게 일치하는 콘텐츠 검색

ex

4차 산업혁명

‘4차산업혁명’ 문구가 정확히 포함된 콘텐츠 검색 (띄어쓰기 포함)

반드시 포함하는 단어 : 입력한 단어를 모두 포합하는 콘텐츠 검색

ex

빅데이터

입력한 검색어와 ‘빅데이터’가 모두 포함된 콘텐츠

제외하는 단어 : 입력한 단어가 포함된 콘텐츠를 검색결과에서 제외 * ‘제외하는 단어’ 조건 사용 시 메인 검색창에 검색어 입력 필수
(메인 검색창에 검색어 미 입력 시 제외하는 단어 입력 불가)

ex

입력한 검색어 : 4차산업혁명, 제외하는 단어 : 빅데이터

‘4차산업혁명’이 포함된 콘텐츠 중 ‘빅데이터’가 포함된 콘텐츠는 제외하고 안내

2. 검색연산자 활용법

검색 연산자 (AND, OR, NOT)는 대문자로 입력해야 합니다.

여러 단어 중 1개 이상 포함 : 각 검색어사이에 ‘OR’입력

ex

인공지능 OR 빅데이터

‘인공지능’, ‘빅데이터’가 모두 포함되거나 둘 중 1개의 단어가 포함된 콘텐츠 검색

정확히 일치하는 단어 :단어/문구를 큰따옴표(””)를 사용해 작성

ex

“4차 산업혁명”

“4차 산업혁명” 문구가 정확히 포함된 콘텐츠 검색 (띄어쓰기 포함)

특정단어 제외 : 제외하고자 하는 단어 앞에 ‘NOT’ 입력

ex

인공지능 NOT 빅데이터

“인공지능” 이 포함된 콘텐츠 중 “빅데이터”가 포함된 콘텐츠를 제외하고 결과안내

활용예제

ex

“4차 산업혁명” AND (인공지능 OR 사물인터넷) NOT 빅데이터

띄어쓰기를 포함해 ‘4차 산업혁명’이란 문구가 완전하게 포함된 콘텐츠 중
“인공지능” 또는 “사물인터넷”이 포함되면서 “빅데이터”는 포함하지 않는 자료
